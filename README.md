# Indian Startup Funding Analysis

Interactive Indian startup funding dashboard analyzing funding trends from 2020 to 2025.

## 🚀 Live Dashboard

[View Interactive Dashboard](https://puneeth-k-07.github.io/INDIAN_STARTUP_FUNDING_ANALYSIS/)

## 📊 Project Overview

This project analyzes Indian startup funding data from 2020 to 2025 using an interactive web dashboard.

### Key Analysis

- Year-wise funding trends
- Funding by sector
- Funding by city
- Funding stage analysis
- Startup funding analysis
- Investor analysis
